# RGB Keyboard — Native Android project

Offline native Android keyboard with individually phase-shifted animated RGB key borders, basic typing, backspace, enter, shift, and symbols toggle.

Build APK via the GitHub Actions workflow in this repository. After a successful run, download the RGBKeyboard-debug-apk artifact, extract it, and install app-debug.apk. Open RGB Keyboard, tap Enable Keyboard, then Select Keyboard in Android settings.

This is a debug APK for testing, not a Play Store release.
